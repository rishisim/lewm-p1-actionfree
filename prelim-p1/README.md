# Proposal 1 Preliminary Tests

This directory contains the staged feasibility work for Proposal 1.

## Layout

| Path | Purpose |
| --- | --- |
| `scripts/` | Stage scripts for timing, latent extraction, comparisons, plotting, and fallbacks. |
| `outputs/` | Compact tracked outputs: reports, summaries, logs, arrays, and plots from the preliminary stages. |
| `convert_pusht_mini_lance.py` | Utility for PushT mini Lance conversion experiments. |

Run scripts from the repository root unless a script says otherwise. They write under `prelim-p1/outputs/`.
